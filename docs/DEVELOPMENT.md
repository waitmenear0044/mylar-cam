# Mylar Cam — заметки разработки

Подробное описание устройства, история версий и порядок работы. Краткое описание для пользователей — в
[README.md](../README.md). Папка `reference/` в публичный репозиторий не входит (см. [THIRD_PARTY.md](../THIRD_PARTY.md)).

Личная Android-камера с ретро-эффектами в реальном времени (Kotlin, Jetpack Compose, CameraX, OpenGL ES 3).
Сейчас версия 0.8.10 (подготовка к публикации): шесть режимов камеры — «Пиксель», «Плёнка», «VHS» (с ЭЛТ), «Cores» (ядра
Dream / Sun / Dark / Circuit), «Градиент» и «Гостинг»; видео и фото со вшитым эффектом, общий штамп даты, пресеты
с силой, миниатюрами и предпросмотром долгим нажатием, экран настроек (сетка, уровень, таймер, кнопки громкости,
качество JPEG, папка). Редактор фото и видео из галереи со слоями (до 5, из «Кубика» — до 10), двумя редакторскими
эффектами — «Газета» и «Выбор цвета» — и режимом «Кубик» (случайная цепочка эффектов); видео обрабатывается
офлайн с прогрессом и отменой. Звук записывается и копируется как есть (отдельной обработки звука нет и не планируется).

## Режимы

- **Пиксель** — вид этапов 2–3: крупные пиксели, приглушённый цвет, выцветшие чёрные, оттенок.
- **Плёнка** — характер плёночного фото, подобран по референсам в `reference/look`: спектральное
  расщепление цвета (кайма), плёночная цветопередача (S-кривая, мягкое плечо, холодные света,
  пурпурные тени), тонировка теней и светов, halation, мягкое цветное зерно, смаз при движении, мягкость.
  «Сила эффекта» масштабирует всё.
- **VHS** — домашнее видео с камкордера 90-х (стадии ntsc-rs, перенесённые в GLSL): сигнал в YIQ в буфере
  строк (по умолчанию 480 строк), горизонтальный lowpass яркости, цвет размазан в ~8 раз сильнее и сдвинут
  вправо, усреднение цвета соседних строк, звон у контуров, видимые строки, чересстрочность; шум ленты,
  дрожание строк, сбитые строки головок внизу кадра, редкая полоса трекинга; дропауты, шлейф, свечение,
  блочность (для «кнопочного телефона»); «● REC» с мигающей точкой в выбранном углу (дата — общий штамп приложения).
  Все «горизонтальные» артефакты идут вдоль горизонтали итогового кадра — вертикального или снятого боком (и у фронтальной камеры).
  ЭЛТ (две категории, всё по умолчанию выключено — старые пресеты не меняются): маска люминофора (RGB-точки /
  апертурная решётка / щелевая маска, сила и размер ячейки в долях кадра; ячейка меньше ~4 пикселей плавно исчезает —
  без муара на уменьшенном превью), кривизна экрана (бочка, скруглённые углы, тёмная кромка, виньетка), цветные облака
  (пастельный шум, растянутый по горизонтали, со сдвигом строк, плывёт со своей скоростью), муар/волна к краям.
  Пресеты: VHS SP, Видео-8, Затёртая кассета, Трекинг, Кнопочный телефон, Лёгкая ностальгия, ЭЛТ-телевизор, Монитор.
- **Cores** — четыре стиля-«ядра» (чипы под режимами; переключение мгновенное, параметры каждого ядра
  хранятся отдельно, у каждого ядра свой активный пресет и своя сила пресета; цвет и текстура подобраны
  по `reference/look/dreamcore`, `sunkor`, `darkcore`, `circuitbend`):
  - **Dream** (дримкор) — молочная насыщенная пастель, зелень в бирюзу, фиолетовые тени, розовые света,
    зелёно-фиолетовые переливы в небе, низкий контраст, дымка, свечение, мелкое зерно, лёгкая постеризация.
    Пресеты: Пригород, Зыбкий сон, Пастель.
  - **Sun** (санкор) — экспозиция с мягким плечом, Orton-свечение, кремово-золотые света, жёлто-зелёная
    зелень, насыщенные красные акценты, тёплая дымка, засветы по краям (в видео медленно плывут).
    Пресеты: Золотой час, Пересвет, Утро в саду.
  - **Dark** (даркор) — бирюзово-синий оттенок, затемнение, сине-зелёные чёрные, туман сильнее к верху
    кадра, холодное свечение, косые штрихи размытия (длина, угол, сила, прозрачность), шум, виньетка.
    Пресеты: Туман, Ночной лес, Дождь.
  - **Circuit** (circuit bend) — постеризация, психоделическая палитра по яркости и оттенку, соляризация,
    дизеринг (Байер или «диффузия»), тёмное в тёмно-синий, инверсия полос, смена каналов; всплески сбоя
    (сдвиг блоков, залипание строк, замирание кадра в видео), палитра и точки ползут по времени.
    На фото всё детерминировано: время и всплеск — на момент съёмки. Пресеты: Соляризация, Кислота, Потеря сигнала.
  - Ядро «Аэро» (эстетика 2000-х) удалено в 0.8.7: сохранённый выбор переключается на Dream, коды его пресетов не принимаются
    («ядро удалено»).
- **Градиент** — кадр в ЧБ по яркости раскрашивается картой градиента (интерполяция точек в линейном свете,
  дизеринг без полос). Ползунки: сила (смесь с оригиналом), контраст до карты, циклический сдвиг, инверсия.
  8 готовых градиентов (Закат, Неон, Тепловизор, Сепия, Лёд, Киберпанк, Лес, Ретро-монитор) — каждый можно править
  и сбросить. Лента градиентов лежит над полосой категорий, «изменить» открывает редактор: полоска с точками (до 30;
  добавить нажатием, перетащить, удалить), цвет точки (HSV и HEX), список градиентов (порядок — перетаскиванием за «≡»,
  новый, дубль, переименовать, удалить свой, сбросить готовый), обмен кодом `MYLAR1:` для одного градиента и для набора;
  «Копировать точку» ставит копию с тем же цветом рядом с выбранной (до 30 точек).
  Лента «Градиент» выбирает только карту (пресет помечается «изменён»), «Пресеты» — полный набор (карта и
  ползунки): по пресету на каждый готовый градиент плюс Закат на плёнке, Неоновый плакат, Тепловизор, Лёгкая
  тонировка и свои. Эффект активен, пока включён режим: «×» у пресета только снимает пресет (вид остаётся),
  без пресета ряд показывает «Пресеты: свой».
- **Гостинг** (только превью и видео; фото сохраняет кадр с экрана) — «глюк-копии»: движущийся объект оставляет
  застывшие копии, пока их не перекроет новое изображение (чувствительность, время жизни в секундах, сила,
  цветовой сдвиг); «эхо»: плавное накопление прошлых кадров (длина в секундах, сила, цветовой сдвиг). Всё по времени
  кадра (одинаково на 24/30/60 fps); история — в уменьшенном буфере (до 1280 по длинной стороне), освобождается при
  уходе из режима. Форма шлейфа (только след, текущий кадр чёткий): чёткий, размытый, пиксельный, блочный
  (макроблоки), «шакальный» (убитый JPEG); размер блока/сила и сила деградации; маска следа хранится в альфе
  истории, форма берётся из её мип-уровней (несколько выборок — fps превью не падает).
  Пресеты: Зал зеркал, Кислотные копии, Старый телевизор, Призрак, Размытый / Пиксельный / Блочный / Шакальный шлейф.
- **Редакторские эффекты** (только в редакторе, как слои):
  - **Газета** — полутоновая печать: ЧБ-растр (угол сетки), «розетка» CMYK (15°/75°/0°/45°), RGB-каналы со своими
    сетками; размер ячейки в долях кадра, контраст точек, смещение каналов, сине-чёрная краска; бумага (белая /
    серая / желтоватая). Пресеты: Газета ЧБ, Цветная розетка, RGB-сдвиг, Старая жёлтая.
  - **Кубик** (значок кубика в конце полосы режимов редактора) — случайная цепочка из 3 / 5 / 7 / 10 слоёв по кнопке
    с кубиком (иконка без подписи; кубик вращается ~400 мс, лёгкая вибрация). Пул — все режимы: Пиксель, Плёнка, VHS (с ЭЛТ), каждое
    ядро Cores, Градиент (готовый или из 2–8 случайных точек), Газета, Выбор цвета; Гостинг — только для
    видео; один режим не больше двух раз. Ползунки — случайно в «безопасном окне» (по умолчанию 10–90% диапазона,
    у «опасных» уже — таблица в `effect/Dice.kt`) с уклоном к середине, непрозрачность слоя 0.5–1, порядок
    случайный; шум и оверлей не трогаются. Результат проверяется на копии кадра 256 px: средняя яркость вне
    0.10–0.90 или почти нет контраста — переброс до трёх раз. Seed броска показан в панели (нажатие — бросок по своему
    seed). Замок на слое (в панели слоёв) оставляет слой при броске. «Скопировать набор» / «Вставить набор» — код
    всей цепочки слоёв `MYLAR1:` (режим, параметры, непрозрачность, видимость, замок, seed; слои удалённых режимов
    пропускаются). После броска звёздочка сохраняет набор («Кубик N», `files/dice_sets.json`): ряд «Сохранённые» —
    нажатие применяет к текущему фото или видео, долгое нажатие — переименовать, скопировать код, удалить.
    Дальше это обычные слои. В камере «Кубика» нет: живая цепочка там потребует рендера `LayerChain`
    в `VhsSurfaceProcessor` (по рендереру и буферам истории на слой) и предела слоёв по замеру fps.
  - **Выбор цвета** — до трёх диапазонов оттенка (пипетка: палец ведёт по картинке, над ним лупа ~72dp с
    увеличением, перекрестием и цветом рамки — средним 5×5 по картинке до эффекта слоя, кружок «текущий | новый»;
    отпускание подтверждает; цвет слота — кружком в шапке панели), подкрутка оттенка, ширина, мягкость,
    отсечка по насыщенности); выбранное остаётся цветным на ЧБ или само становится ЧБ; ЧБ-часть — через кривую
    (монотонный сплайн, точки перетаскиваются). Пресеты: Красный остаётся, Небо в чёрный, Тёплые тона остаются.
- **Шум** (все режимы, по умолчанию выключен) — жёсткий цифровой шум дешёвой камеры: яркостный, цветной,
  крупность, «в тенях сильнее».
- Размеры (кайма, зерно, шум, свечение, размытия и сдвиги «VHS») заданы в долях полного кадра: превью, видео и фото любого формата
  выглядят одинаково.
- Покадровые эффекты привязаны ко времени кадра, а не к числу кадров: шум, зерно, дрожание строк, дропауты,
  трекинг и чередование полей меняются 30 раз в секунду при любой частоте; доля предыдущего кадра в смазе
  и шлейфе пересчитывается от длительности кадра (a^(dt/dt₃₀)) — при 30 fps вид прежний.
- Случайный рисунок шума (зерно, шум ленты, дропауты, полоса трекинга) у каждого фото и каждого ролика свой
  (внутри ролика шум живой); зерно генератора в файле не хранится.
- Запоминаются: режим, параметры (в т.ч. «REC» у «VHS»), частота кадров, активный пресет и его сила, «Фото/Видео»,
  формат кадра, вспышка/фонарик, штамп даты, настройки приложения, набор градиентов.

## Интерфейс

- **Lock превью**: размер и положение превью зависят только от формата кадра. Панели категорий, ряд пресета, лента
  градиентов и список пресетов лежат поверх нижней части превью с полупрозрачным фоном; пока тянешь ползунок, панель
  почти прозрачная и остальные строки гаснут (возврат через ~300 мс). Повторное нажатие на выбранный режим
  сворачивает всё управление эффектом (категории, панель, ядра, ряд пресета, ленту градиентов, список пресетов) —
  остаются полоса режимов и спуск; следующее нажатие возвращает как было. Другой режим всегда развёрнут; после
  перезапуска — развёрнуто.
- **Верхняя панель** (помещается в 360dp без прокрутки): вспышка (фото: Выкл → Авто → Вкл; видео: фонарик, можно во
  время записи; фронтальная: экранная вспышка в фото), формат кадра, «FX» — включить/выключить эффект целиком
  (и во время записи), штамп даты (нажатие — вкл/выкл, долгое — настройки), переворот камеры, настройки
  (во время записи серые и недоступны). fps — справа в ряду зума, метка таймера — слева.
- **Кадр** (нажатие на таблетку формата): формат 3:4, 1:1, 4:5, 2:3, 9:16 и качество; во время записи не меняются.
  Качество в фото — размеры 4:3, которые камера реально отдаёт приложению
  (обычные и «медленные» большие, `PREFER_HIGHER_RESOLUTION_OVER_CAPTURE_RATE`), плюс «Макс»;
  в видео — 720p / 1080p / 4K по возможностям камеры и кодека (4K помечен «может тормозить») и частота
  кадров 24 / 30 / 60 fps (по умолчанию 30): показываются только частоты, для которых CameraX сообщает
  диапазон для этой сессии (камера + разрешение + эффект, `getSupportedFrameRateRanges(SessionConfig)`) и
  которые тянет кодер H.264. Частота задаётся всей сессии — превью, запись и файл идут на ней.
  Если камера не тянет выбранное вместе с превью и эффектом, качество (а затем частота) само снижается на шаг;
  если превью заметно не держит частоту (меньше 80% через 4 с) — тоже шаг вниз с сообщением.
  Счётчик fps оранжевый, если меньше 90% выбранной частоты.
  Превью и запись идут одним потоком эффекта, и CameraX может молча уменьшить его, если сессия не держит
  частоту в заказанном размере. Поэтому в режиме видео фото-поток не привязывается (переключение
  «Фото/Видео» перепривязывает камеру), а после привязки реальный размер видео сверяется с выбранным:
  при 24/60 fps — возврат к 30 с сообщением, при 30 — сообщение с реальным размером. В меню качества
  видно «Пишется: Ш×В».
  Режим максимального разрешения сенсора CameraX 1.6 выбирать не позволяет — он только показан в сведениях.
- **Сведения о камерах** (кнопка «Камеры» в справке): все камеры, видимые приложению (и физические),
  размеры фото и видео, режим максимального разрешения, ULTRA_HIGH_RESOLUTION_SENSOR, GL_MAX_TEXTURE_SIZE, память.
- **Ориентация.** Экран камеры (и все остальные экраны) всегда портретный и при повороте телефона не перестраивается:
  окно превью меняется только при смене формата. Угол телефона берётся из датчика (OrientationEventListener,
  округление до 90°, независимо от системного автоповорота; «вверх ногами» игнорируется). При повороте на месте
  за ~200 мс поворачиваются только иконки и подписи: верхняя строка, значки режимов, ядер и категорий, ★ «Пресеты», переворот камеры,
  миниатюра и галерея, спуск, «Фото/Видео», таблетка зума; длинная подпись, если повёрнутая не влезает в свой ряд,
  уменьшается. Не поворачиваются превью, шкала зума, ряд силы пресета, листы; панель категории поворачивается
  целиком (см. ниже). Рядом с форматом — значок телефона
  (вертикально/горизонтально): в какой ориентации сохранится снимок.
  Фото сохраняется в ориентации телефона в момент нажатия (боком: 3:4 → 4:3, 9:16 → 16:9, 1:1 остаётся),
  ориентация видео фиксируется в момент старта записи; во время записи иконки не вращаются. Строки «VHS», зерно,
  оверлей REC/дата идут вдоль горизонтали готового файла, оверлей — в выбранном углу готового кадра (в превью
  при этом он лежит так, как ляжет в файл). Область кадра на сенсоре одна и та же, поэтому поворот не перепривязывает камеру.
- **Превью** выбранного формата всегда целиком и не перекрыто (кроме временных индикаторов); долгое нажатие —
  временно оригинал, тап — фокус и экспозиция, два пальца — зум.
- **Первый запуск**: экран-объяснение и один запрос камеры и микрофона (на Android 8–9 ещё памяти; с Android 10
  сохранение через MediaStore разрешений не требует). Без микрофона всё работает, видео пишется без звука
  (с сообщением). Без камеры — экран «Нет доступа к камере»: «Разрешить», а после отказа «больше не спрашивать» —
  «Открыть настройки»; справка открывается и так.
- **Зум**: над спуском таблетка с текущим зумом («1×», «2.3×», от 10× — целое). Тап или перетаскивание по ней, а также
  щипок раскрывают горизонтальную шкалу; через ~3 с без касаний она снова сворачивается. Шкала логарифмическая от
  минимального до максимального зума камеры (`zoomState` в рантайме), крупные риски с подписями — «круглые» значения
  из диапазона (0.5, 1, 2, 3, 5, 10, 20…) и собственный зум физических камер (`intrinsicZoomRatio`): к ним палец
  примагничивается с лёгкой вибрацией. Оранжевая риска и таблетка — текущее значение. Если камера зум не
  поддерживает (диапазон 1.0–1.0), таблетки и шкалы нет.
  Зум сохраняется при смене режима эффекта и перепривязке, сбрасывается на 1× при смене передней/задней камеры;
  работает и во время записи.
- **Тап-фокус и экспозиция**: FocusMeteringAction (AF + AE + AWB) в точке тапа, через 4 с — снова непрерывный
  автофокус; кольцо оранжевое — поймал, полупрозрачное белое — нет. Точка касания в долях видимого кадра
  переводится в координаты сенсора с учётом кадрирования формата, зеркала фронтальной камеры и поворота сенсора
  (без матрицы буфера превью: после эффекта она зависит от устройства). Рядом — вертикальный ползунок с солнцем
  (диапазон и шаг из `exposureState`; если компенсации нет — ползунка нет); сбрасывается при смене камеры.
- **Фото из галереи** (кнопка рядом с миниатюрой): системный Photo Picker (где его нет — ACTION_OPEN_DOCUMENT),
  без READ_MEDIA_*. Экран обработки — те же режимы, ядра, категории, пресеты, сила пресета и «×», общая с камерой
  текущая настройка; долгое нажатие — оригинал. Превью — на уменьшенной копии, «Сохранить» — полноразмерный тайловый
  PhotoProcessor по исходному файлу (EXIF-ориентация в пикселях до эффекта, откат по памяти) в Pictures/VHS.
  Формат: «Исходный» или формат в ориентации фото, максимальное кадрирование без растяжения. Дата оверлея «VHS» —
  дата съёмки из EXIF, иначе дата файла.
- **Палитра** — `ui/Colors.kt` (одно место): акцент оранжевый (выбранное, спуск, активные чипы и категории, текущий
  зум, «поймал» у фокуса), фиолетовый `#9B6BFF` — только микроэлементы (разделитель в меню, точка «изменён»,
  остаток дорожки ползунка, мелкие риски шкалы, звёздочка готового пресета), текст и иконки белые (второстепенные —
  с прозрачностью), красный — запись и ошибки, панели тёмные тёплые. Тема Material тоже собрана из этих токенов.
- **Сетка** — `ui/Dimens.kt` (одно место): единица 8dp, отступы кратны 4/8dp; кнопки-иконки 48×48dp, таблетки
  формата и качества одной высоты 48dp и одной ширины (по самому длинному возможному значению), спуск 72dp.
  Однотипные элементы стоят на общей оси и распределены равномерно: верхняя полоса, режимы, ядра, категории
  (если не помещаются — фиксированный промежуток и прокрутка), блок спуска (миниатюра и галерея | спуск | капсула).
- **Ползунки** в панели категории — в две строки: название и значение, под ними ползунок на всю ширину панели
  (в портрете и в повёрнутом виде одинаково).
- **«Фото/Видео»** — одна капсула 2 × 48dp с двумя значками; подложка плавно (~150 мс) переезжает под выбранный.
- **Листы и диалоги экрана камеры** (пресеты, действия с пресетом, ввод имени, удаление, формат, качество)
  поворачиваются вместе с телефоном как единое целое (`ui/Overlay.kt`: окно на весь экран, рамка с поменянными
  шириной и высотой, поворот вокруг центра); пресеты — по одному на строку. Справка, «Сведения о камерах» и
  экран обработки фото остаются портретными.
- **Нижний блок**: значки режимов (без подписей; название — коротким ярлыком на ~1.5 с после выбора, у значков
  есть описание для доступности) и ★ «Пресеты» справа; у «Cores» — строка значков ядер (так же, одной строкой);
  полоса значков категорий (без подписей, название — в шапке открытой панели); панель категории (до 4 ползунков,
  «Сбросить», «✕»); ряд активного пресета (название, «×» — сброс к нейтральным значениям, «Сила пресета» 0–150%);
  ряд спуска: миниатюра и «Фото из галереи» слева, «Фото/Видео» значками справа. Выбранный значок — оранжевый
  в оранжевой рамке. Значки векторные (`res/drawable/ic_mode_*`, `ic_core_*`, `ic_capture_*`, `ic_help`), цвет — из палитры.
- **Панель категории при повороте телефона** поворачивается целиком вокруг своего центра (~200 мс): содержимое
  компонуется как в портрете, но в рамке с поменянными шириной и высотой, поэтому у держащего телефон боком
  подписи ползунков, значения, «Сбросить» и «✕» читаются как обычно, а внутри можно прокрутить. Место панели в
  раскладке то же; повёрнутая панель не ниже 220dp, чтобы строки поместились по ширине.
- **Полноэкранный режим** на всех экранах: строка состояния и навигация скрыты (по свайпу от края показываются
  временно), интерфейс рисуется под вырезом; блок управления держится вне выреза, вне зоны жеста «назад» у боковых
  краёв и зоны жеста «домой» внизу (отступы из WindowInsets в рантайме). Листы и диалоги тоже без системных панелей.
- На маленьком экране настройки эффекта прокручиваются внутри блока, превью не исчезает, спуск всегда на месте.
- **Пресеты**: готовые (★) и свои; сохранить текущее, переименовать, удалить; маркер «изменён»
  и «Вернуть»; обмен кодом `MYLAR1:…` (JSON в Base64; старые коды `VHSCAM1:` читаются).
  Ползунки категорий показывают базовые значения, сила пресета смешивает их с нейтральными.
  Долгое нажатие (~350 мс, лёгкая вибрация) на строку пресета, ряд активного пресета, градиент или ядро «Cores»
  временно показывает их на превью (список и панели почти прозрачны, название — ярлыком над полосой
  категорий); отпускание возвращает прежние настройки, короткое нажатие применяет как раньше.
  Прокрутка списков выбора (пресеты, режимы, градиенты, панели редактора) запоминается для каждого режима
  и слоя на время работы приложения; список, которого ещё не было, открывается на выбранном элементе.
  Свои пресеты лежат в `files/presets.json` приложения.
- **Пресеты** — компактный выпадающий список под кнопкой ★ (не выше ~45% экрана): миниатюра (тот же рендерер на кадре,
  замороженном при открытии), название, звёздочка у готовых, «⋮» у своих, точка «изменён». Нажатие применяет пресет,
  список остаётся открытым; «Сохранить текущее», «Вставить код», «Скопировать код».
- **Настройки** (шестерёнка): сетка (выкл / 3×3 / с диагоналями), уровень горизонта (акцентный при ±1°), таймер
  (3 / 5 / 10 с, крупный отсчёт на превью, повторное нажатие отменяет, для видео — задержка старта), кнопки громкости
  (спуск / зум / ничего), качество JPEG, папка сохранения (по умолчанию «Mylar» в Pictures и Movies; старые файлы не
  трогаются), вибрация, режим при запуске, версия. Применяются сразу.
- **Штамп даты** (все режимы, фото и видео): рисуется поверх итогового кадра после эффектов — чёткий, в выбранном
  углу итогового кадра (и у снятого боком), у фронтальной не зеркальный. Настройки: дата текущая или своя (календарь
  и время), формат (12.11.26 / 26 11 12 / 12 NOV 2026), время, шрифт (цифровой сегментный / моноширинный), цвет
  (5 готовых и свой), размер в долях кадра, прозрачность, угол; живой образец в листе. У файлов из галереи по
  умолчанию — дата съёмки из EXIF / метаданных (иначе дата файла).
- **Редактор** (фото или видео из галереи, Photo Picker): слои (до 5) — у каждого свой режим, настройки, пресеты,
  сила и непрозрачность; видимость, удаление, порядок перетаскиванием. Панели — поверх превью, как в камере.
  Каждое открытие файла — с чистого листа (0 слоёв, режим не выбран, исходник); состояние сеанса (`EditorSession`)
  живёт только пока редактор открыт (переживает переход в справку). Кнопка «К исходному» убирает всё, «Отменить» в
  snackbar возвращает.
  Долгое нажатие по превью — оригинал. Фото сохраняется в полном разрешении тайлами по слоям (промежуточный результат
  больше 16 Мп — во временном PNG без потерь), шум у каждого сохранения свой. Повторное нажатие на режим
  активного слоя сворачивает его панель. Видео: плеер — «Воспроизвести/Пауза», время, ползунок позиции, звук,
  повтор (по умолчанию вкл.); вся цепочка слоёв в реальном времени на уменьшенном превью (длинная сторона до 720,
  при нехватке скорости уменьшается; звук и время не уплывают — лишние кадры пропускаются, в углу метка
  «упрощённое воспроизведение»); история «VHS»/«Гостинга» по времени кадра, сброс при перемотке; долгое нажатие —
  оригинал, не останавливая воспроизведение; пауза при диалогах и сворачивании. Сохранение — офлайн-рендер (MediaCodec + GL, поворот из метаданных вшивается в пиксели, история «Гостинга» и
  «VHS» по кадрам, звук копируется как есть), разрешение исходное / 1080p / 720p, прогресс, «Отмена» (файл не
  остаётся), уведомление по готовности, результат в Movies/<папка>.
- **Справка по эффектам** — только про эффекты: режимы и ядра, для каждого ползунка объяснение и живое демо на
  тестовой картинке («без эффекта | с эффектом»). Открывается маленьким значком ⓘ в шапке листа «Пресеты»,
  пунктом в «Сведениях о камерах» и с экрана «Нет доступа к камере» (работает без разрешения на камеру).

## Как устроено

- `effect/` — `EffectMode`, параметры режимов (`PixelParams`, `FilmParams`, `VhsParams`, `NoiseParams`), `EffectSettings`
  (в т.ч. `effective()` — параметры с учётом силы пресета), `CameraOptions` (формат кадра, вспышка),
  `SettingsStore`; `EffectSpecs`/`VhsSpec` — подписи, диапазоны, нейтральные значения, категории и тексты справки;
  `Presets`/`PresetManager` — пресеты; `ParamsJson` — JSON параметров. Новый режим =
  элемент `EffectMode`, свой data class, свой рендерер в `gl/` и ветка в `EffectRenderer`.
- `gl/VhsRenderer` — «VHS»: проходы signal → luma → chroma → bloom → composite (ping-pong с предыдущим
  кадром) в маленьком буфере строк в координатах итогового портретного кадра, затем output — растягивание
  строк на выход с плавным переходом между строками и оверлеем (`gl/VhsOverlay`, текст через Canvas).
  Поворот и зеркало CameraX после эффекта учитываются матрицей «итоговый кадр → буфер».
- `gl/CoresRenderer` — «Cores»: у Dream/Sun/Dark уменьшенная копия кадра и два размытия (тот же гауссиан,
  что halation «Плёнки»), проход ядра (`cores_dream/sun/dark.frag`) и зерно «Плёнки» (`film_output.frag`);
  у Circuit — один проход `cores_circuit.frag` и буфер последнего кадра для замирания. Направления (верх
  кадра, угол штрихов, края засветок, сдвиги блоков) — в координатах итогового кадра, как у «VHS».
  Параметры ядер — `effect/CoresParams`, описание и категории — `effect/CoresSpec` (`ModeSpec.categoriesOf`:
  категории зависят от выбранного ядра).
- `gl/EffectRenderer` — рендер режима (`PixelRenderer`, `FilmRenderer`, `VhsRenderer`, `CoresRenderer`) в полном кадре 3:4, затем общий
  финальный проход `post.frag`: обрезка до формата и цифровой шум (без них — прямой путь, как раньше).
  Один и тот же код работает с кадрами камеры (`samplerExternalOES`) и с фото (`sampler2D`).
- `camera/VhsCameraEffect` + `camera/VhsSurfaceProcessor` — `CameraEffect` для PREVIEW и VIDEO_CAPTURE.
  Формат кадра задаётся ViewPort CameraX; процессор рисует эффект по полному входному кадру, а обрезку
  ViewPort применяет сам в финальном проходе.
- `camera/VhsCameraController` — привязка камеры (Preview + VideoCapture + ImageCapture + эффект, ViewPort),
  запись в `Movies/VHS/VHS_гггг-мм-дд_чч-мм-сс.mp4`, битрейт по режиму и разрешению (720p: 5/14/10/14, 1080p: 10/24/18/24, 4K: 30/60/45/60 Мбит/с для Пикселя/Плёнки/VHS/Cores,
  сильный шум ×1.3; 60 fps ×1.5, 24 fps ×0.85),
  вспышка, фонарик, экранная вспышка, остановка записи при сворачивании.
- `camera/PhotoProcessor` — фото в полном разрешении тайлами 1536 px: снимок читается кусками
  (`SourceImage`, `BitmapRegionDecoder`), halation, сетка «Пикселя» и буфер строк «VHS» считаются один раз по уменьшенной
  копии, тайлы рисуются тем же `EffectRenderer` с окном в координатах полного кадра (без швов) и сразу
  складываются в итоговый кадр; при нехватке памяти — повтор в 71% и 50% размера. Поворот и зеркало —
  в пикселях; JPEG 93 в `Pictures/VHS/IMG_….jpg`.
- `camera/GalleryPhoto` — готовое фото: байты, EXIF-ориентация, дата съёмки, уменьшенная копия для превью;
  `ui/EditorScreen` — экран обработки; `ui/CameraOverlays` — жесты превью, кольцо фокуса, ползунок экспозиции;
  `ui/ZoomScale` — таблетка и шкала зума; `ui/DeviceOrientation` — угол телефона по датчику и поворот иконок на месте;
  `ui/ControlPanel` — общие для камеры и обработки настройки эффекта (значки, панель с поворотом `TurnWithDevice`);
  `ui/Colors` — палитра; `ui/FullScreen` — скрытие системных панелей (окно активити, листы, диалоги).
- Поворот эффекта: процессор разбирает матрицу CameraX (обрезка ViewPort, иногда с поворотом на 90° и отражением у
  фронтальной) и считает эффект по полному кадру, а «горизонталь» берёт из угла между сенсором и ориентацией съёмки.
- `AppInfo` и `version.properties` — имя и версия (одно место). `DebugHooks` — отладочные подмены, только в debug
  (`src/debug`), в release пустая заглушка (`src/release`): `adb shell am start --activity-single-top -n
  com.vhscam.app/.MainActivity --ei debug_orientation 90` подменяет датчик ориентации (0 / 90 / 270).
- Иконка — адаптивная (`res/mipmap-anydpi-v26`, фон, передний план и монохромный слой для тематических иконок).
- `camera/CameraCaps` — что камера отдаёт приложению (размеры фото/видео) и текст экрана сведений.
- `gl/OfflineRender` — общий офлайн-рендер (фото и справка), `ui/TestImage` — тестовая картинка справки.
- `gl/DebugPresetRender` — самопроверка пресетов (только debug-сборка): все готовые пресеты по картинкам из
  `files/debug_look_in` → `files/debug_look_out`; запуск
  `adb shell am start -n com.vhscam.app/.MainActivity --ez debug_render_presets true`.
- Шейдеры: `app/src/main/assets/shaders/` (`pixel*.frag` — «Пиксель», `film_*.frag` — «Плёнка», `vhs_*.frag` — «VHS», `cores_*.frag` — «Cores»,
  `post.frag` — формат и шум).
- `videoimport/` — экран этапа 1 (выбор и проигрывание готового видео), сейчас не используется.

## Сборка

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew assembleDebug assembleRelease
```

Имя и версия задаются только в `version.properties` (`appName`, `versionName`, `versionCode`). Новый этап: поднять
версию там (этап 8 → 0.8.0 / 800, правка внутри этапа → следующая цифра). `assembleRelease` сам кладёт APK в
`output\Mylar-Cam-<версия>.apk` — это release-сборка без отладочных подмен, подписанная тем же ключом, что и прежние

## Установка на телефон

Нужен Android 8.0 или новее.

### Вариант 1: перенос файла

1. Скопируйте `output\Mylar-Cam-0.8.10.apk` на телефон (USB в режиме «Передача файлов», Google Диск, Telegram «Избранное» и т. п.).
2. Откройте файл на телефоне через «Файлы» / «Загрузки».
3. Android попросит разрешить установку из этого источника: «Настройки» → разрешить → назад → «Установить».
4. Play Защита может предупредить о неизвестном приложении — «Всё равно установить».

### Вариант 2: по кабелю через adb

1. На телефоне включите режим разработчика: «Настройки» → «О телефоне» → 7 раз нажать «Номер сборки».
2. «Настройки» → «Для разработчиков» → включить «Отладка по USB».
3. Подключите кабель, на телефоне подтвердите «Разрешить отладку по USB» для этого компьютера.
4. Проверьте подключение и установите:

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb devices
& $adb install -r C:\Projects\vhs-cam\output\Mylar-Cam-0.7.3.apk
```

`devices` должен показать устройство со статусом `device` (если `unauthorized` — подтвердите запрос на телефоне).
Ключ `-r` переустанавливает поверх старой версии с сохранением данных.

Логи приложения при отладке: `& $adb logcat --pid=$(& $adb shell pidof com.vhscam.app)`.
